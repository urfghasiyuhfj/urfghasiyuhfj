## 一、项目概述

### 1.1 项目背景

PPM（Parts Per Million）系统用于统计与分析供应商产品质量，通过处理 SGMW 数据库中的可疑物料统计和供应商供货量数据，计算各基地、供应商的 PPM 值，并提供多维度分析与可视化。

### 1.2 项目目标

1. 从 SGMW 数据库获取可疑物料统计和供应商供货量数据
2. 计算供应商 PPM 和基地品牌 PPM
3. 提供故障类别分析、失效模式分析
4. 提供多维度可视化（饼图、直方图、Top 排名）
5. 建立 PPM 数据库，存储供应商档案和各基地详细 PPM

### 1.3 系统定位

- 数据来源：SGMW 数据库（可疑物料统计、供应商供货量）
- 核心功能：PPM 计算、多维度分析、可视化展示
- 数据存储：新建 PPM 数据库（供应商档案、各基地详细 PPM）

### 3.2 PPM 计算模块

#### 3.2.1 功能描述
基于可疑物料和供货量数据，计算供应商 PPM 和基地品牌 PPM。

#### 3.2.2 计算公式

PPM = (不合格数 / 供货量) × 1,000,000

#### 3.2.3 计算规则

| 规则类型 | 规则说明 |
|----------|----------|
| 不合格数口径 | 仅统计 supplier_resp = 'Y'（供应商责任）的可疑物料 |
| 供货量口径 | 排除零件名称包含「螺栓」「螺母」「卡扣」的行 |
| 时间维度 | 按月份计算（yyyyMM 格式） |

#### 3.2.4 计算维度

| 类型 | 维度 | 聚合键 | 说明 |
|------|------|--------|------|
| A | 基地×供应商×月份 | (ppm_month, base_code, supplier_code) | 该基地该供应商当月不合格数/供货量 → PPM |
| B | 供应商×月份 | (ppm_month, supplier_code) | 该供应商在所有基地的不合格数合计/供货量合计 → PPM |
| C | 基地×月份 | (ppm_month, base_code) | 该基地所有供应商的不合格数合计/供货量合计 → PPM |
| D | 全系统×月份 | (ppm_month) | 所有基地、所有供应商的不合格数合计/供货量合计 → PPM |

#### 3.2.5 功能点

**F2.1 自动计算**

| 功能项 | 说明 |
|--------|------|
| 触发时机 | 导入可疑物料或供货量后，自动触发当月 PPM 计算 |
| 手动计算 | 支持手动触发指定月份的 PPM 计算 |

**F2.2 计算结果存储**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| ppm_month | VARCHAR(8) | 月份 (yyyyMM) |
| base_code | VARCHAR(32) | 基地代码 |
| base_name | VARCHAR(64) | 基地名称 |
| supplier_code | VARCHAR(32) | 供应商代码 |
| supplier_name | VARCHAR(128) | 供应商名称 |
| defect_count | INT | 不合格数 |
| supply_qty | INT | 供货量 |
| ppm | DECIMAL(12,2) | PPM 值 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

**F2.3 计算差异提醒**

| 差异类型 | 说明 |
|----------|------|
| PPM 值变化 | 计算后与历史数据对比，PPM 值变化超过阈值 |
| 新增供应商 | 出现新供应商 |
| 数据缺失 | 历史有数据但本次计算缺失 |

#### 3.2.6 接口设计

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/ppm/calculate | POST | 触发 PPM 计算 |
| /api/ppm/summary | GET | 查询 PPM 汇总 |
| /api/ppm/trend | GET | 查询 PPM 趋势 |
